# Student Management System

A full-stack Student Management System developed as part of the Veda Technology internship Task 9.

The application provides complete CRUD functionality for managing student records.

## Features

- Add new students
- View all students
- View individual student records
- Edit student information
- Delete students
- SQLite database persistence
- RESTful API
- Responsive frontend
- Form validation
- Duplicate email prevention
- Confirmation before deleting a student

## Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- CORS

### Database
- SQLite

### Development Tools
- VS Code
- npm
- Nodemon
- Git
- GitHub
